## 절차

1. **톤 보정(매번)** — 지어내지 말고 실측한다.
   - 받는사람이 있으면 `slack_search_users`로 user_id 해석.
   - `from:<@U09EREVN6G7>` 로 내 최근 메시지 10~20개를 읽는다(가능하면 그 상대 DM
     `in:<@상대id>` 로 좁혀서). 최근 어투·이모지 습관을 눈으로 확인하고 그걸 따른다.
   - 아래 규칙은 그 위에 얹는 가드일 뿐 — 실제 메시지가 규칙과 다르면 실제를 따른다.

4. **발송** — 명시적 OK가 있을 때만 `slack_send_message`로 해당 DM 채널에 발송.
   OK 없이는 초안만. (외부 메시지 발송은 항상 확인 후.)

## 말투 규칙 (실제 메시지에서 정제)

- **담백한 합니다체/해요체 혼용. 짧고 직접적. 용건·결론 먼저.** 한 용건이면 2~4문장.
- **이모지 최소.** `:pray:` `:raised_hands:` 색동그라미(`:red_circle:` 등) 남발 금지.
  기술 다항목을 정리할 때만 `1. 2.` 또는 `① ②` 정도. 가벼운 `!` 는 OK.
- 어미: "~더라고요 / ~까요? / ~습니다 / ~할게요 / ~같습니다". 가끔 "넵 / 앗 / ㅎ / ~습니당".
- **과한 공손·격식 지양** — "여쭤봐요!", "감사합니다" 반복, 굽신거리는 톤 X. 동료한테 편하게.
- 기술 얘기는 구체적으로(엔드포인트·필드·실측 수치 그대로), 군더더기 없이.
- **"저희" 금지** — 나 혼자다. "제가/저는/제 쪽에서"로 쓴다. ("저희가 처리하겠습니다" X →
  "제가 처리하겠습니다" O)
- 물어보는 DM은 "이런 상황인데 이게 맞을까요?" 식으로 짧게. 결론 없이 늘어놓지 않는다.
